
# Моделювання планувальника процесів бортового комп'ютера космічного апарата
Програма моделює роботу планувальника процесів бортового комп'ютера та порівнює алгоритми планування за часом очікування, часом виконання та кількістю пропущених дедлайнів.


# Алгоритми
- FIFO (First In, First Out)
- SJF (Shortest Job First)
- Round Robin (квант часу q = 2)
- Priority без витіснення
- Priority з витісненням


# Сценарії
1. Штатна робота: критична задача керування орієнтацією надходить першою.
2. Аварійна ситуація: тривала наукова задача вже виконується, коли надходить критична задача аварійної стабілізації.

Параметри задач (час надходження, тривалість, пріоритет, дедлайн) є модельними і не відповідають конкретному космічному апарату.


# Показники
- Час виконання = час завершення − час надходження
- Час очікування = час виконання − тривалість задачі
- Дедлайн пропущено, якщо час виконання більший за допустимий


# Структура проєкту
`data.py` - набори задач і квант часу 
`algorithms.py` - алгоритми планування 
`metrics.py` - розрахунок показників 
`main.py` - запуск моделювання та вивід таблиць
